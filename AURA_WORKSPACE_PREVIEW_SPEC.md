# Aura workspace preview

This local preview recreates the functional surface area of the reference management products in Aura's brand system. It is a UI specification and prototype; controls persist only in browser memory or local page state where indicated.

## Navigation

| Aura screen | Previewed functions | Future connection |
| --- | --- | --- |
| Command Center | agency overview, revenue, activity, quick actions | Creator data bridge and agency database |
| Creator Accounts | roster search, create creator, status and workspace cards | Creator profile service |
| Campaign Studio | create campaign draft, audience selection, review queue | Creator approval and message delivery service |
| Collections | create and browse working lists | Collection records and membership rules |
| Statistics | date range selection, audience and performance views, export affordance | Derived analytics contract |
| Inbox Command | inbox list, transcript, internal note surface, AI approval status | Local companion and scoped conversation feed |
| Conversation Intelligence | response timing, topics, engagement, priority queues | Local-first analytics companion |
| Creator Data Bridge | consent boundary, sharing scope, connection state | Encrypted local bridge and authenticated sync |
| AI Persona and Knowledge Base | response style, creator guidance, privacy surface | Creator-controlled knowledge service |
| Content Protection | detection queue, evidence review, notice preview | Monitoring and case-management services |
| Settings | alert, summary, protection and privacy preferences | Per-workspace preferences |
| Admin | team members, invitations, roles and audit activity | Role-based access control and audit log |

## Preview rules

- Buttons that create an item add it to the page immediately.
- Campaigns remain drafts; no message is sent.
- Account connections remain unavailable until the creator installs and approves the local data bridge.
- Analytics figures are representative preview data and show the intended layout, filters and decision points.
- The final implementation keeps the Aura black, burgundy and gold visual system on every screen.

## Acceptance checklist

1. Every sidebar item resolves to a usable screen instead of a 404 page.
2. Each screen includes an obvious primary action and a visible empty or preview state.
3. Creator, campaign, collection, settings and admin controls respond without a backend.
4. The preview works on desktop and narrow mobile layouts.
